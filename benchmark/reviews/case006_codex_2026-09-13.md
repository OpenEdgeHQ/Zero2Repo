### D01：重复装饰 callback 的参数消费语义

28 条分布在 F03（7）、F04（3）、F05（11）、F09（7）。F03/F05 等 helpers 会用同一 callback 创建不同参数配置的对比命令。候选保留 callback 上的参数元数据，后面的命令因此累积旧参数、类型、默认值或 deprecation 设置。

一个公开 API 对照是：先对共享 callback 声明浮点参数，再声明字符串参数；第二个命令仍返回 float，且参数对象从 1 个变成 2 个。换成新的 callback 后，字符串转换正确。

[Interface Contract](../cases/case006/public/Interface_Contract.md) 的 `argument` 条款说装饰器返回同一个函数，`command` 条款说此前附着的参数注册到新命令。相关条款没有清楚说明 command 创建后是否消费这些声明，或再次装饰同一 callback 时如何隔离已有声明。因此不能直接把 28 个失败解释为 28 个独立核心功能缺失，也不能仅凭修候选后通过就断言测试正确或错误。

在事后 reviewer 副本中，仅消费这份参数元数据，原套件变为 475/476，只剩终端问题。这证明共同机制，不决定契约归责。

**请维护者确认：** 是要明确规定消费/复用语义，还是让仅用于类型、文件等对照的 helpers 使用独立 callback，并为复用另设明确测试。本 PR 不替维护者改写题面或放宽断言。

### T01：PTY 是否应有 controlling terminal

失败测试是 `F11_acceptance.py::test_pause_prints_and_waits_when_interactive`。`_helpers.start_python_on_tty` 将 PTY slave 接到 stdin/stdout/stderr，但没有建立 controlling terminal。候选打开 `/dev/tty` 时报 `OSError: [Errno 6]`。

不改候选代码的环境对照结果如下：

| 环境 | stdin/stdout isatty | 收到按键后继续 | 退出码 |
|---|---|---|---:|
| 只有 stdio PTY | True / True | 否，`/dev/tty` 打开失败 | 1 |
| 相同 PTY，加 `setsid` 和 `TIOCSCTTY` | True / True | 是，输出独立 DONE 行 | 0 |

据此，先前将该失败直接归为实现错误的结论应撤回。`pause` 契约要求 interactive 时等待按键，但没有说明是否必须支持无 controlling terminal 的 tty stdio。若要求支持，候选需要更稳健的输入路径；若 fixture 意在模拟控制终端，应补齐环境设置。请先明确这一边界。

## 通过项发现的漏检

### B01：36 个 F12 测试通过，实际 Bash 路径补全仍有缺陷

用原候选声明 `Path()` 类型的 `--input` 参数，在工作目录放置 `alpha.txt`，加载其生成的 `bash_source` 脚本，再调用已注册的补全函数处理 `probe-cli --input al`，得到：

```text
declare -a COMPREPLY=([0]="file,al")
```

没有产生真实文件名 `alpha.txt`。候选的 complete 模式输出了路径协议标记，Bash 注册函数却把整行直接当作候选，没有交给 shell 执行路径补全。

PRD FP-12 要求文件/路径类型请求 shell 补全路径。目前 `test_bash_source_prints_script_skips_callback`、`test_four_source_modes_are_shell_specific` 主要验证非空、callback 被跳过、输出不同；没有将注册脚本接到真实 shell 的文件候选流程。

建议加入真实 shell 注册及文件/目录补全断言。Zsh、Fish、PowerShell 的完整交互集成未执行，不作已通过声明。

### E01：denylist 未生效，环境已含上游库

公开 case006 没有 `source/denylist.json`；`load_denylist` 返回 `None`，默认 enforcement 参数并不能产生有效的安装/import 拦截。未由 agent 修改的 image 中已有 `click==8.2.1` 与 `typer==0.20.0`。网络域名阻断无法阻止读取已安装的实现。
